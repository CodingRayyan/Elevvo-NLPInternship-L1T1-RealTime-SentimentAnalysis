# Real-Time Sentiment Analysis on Product & Movie Reviews 💬

This project performs **real-time sentiment analysis** on product and movie reviews, classifying them as **Positive 😄** or **Negative 😡** using **Natural Language Processing (NLP)** and **Machine Learning (ML)** models. It can also fetch **YouTube video comments** and analyze their sentiment instantly, making it **unique and interactive**.

**Key Features:**  

- ⚡ Analyze **manual reviews** or **YouTube comments** in **real-time**.  
- ✨ Highlight **positive and negative words** in reviews.  
- 🧠 Uses **Logistic Regression** & **Naive Bayes** models with NLP preprocessing: lowercasing, stopwords removal, lemmatization, and vectorization.  
- 📊 Displays **confidence scores** and **bar charts** for insights.  
- 🎨 Interactive **Streamlit app** with **dark/light mode**, animations, and enhanced UI.  
- 📝 Includes example reviews for quick testing.  

**Tech Stack:**  
- **Python Libraries:** Numpy, Pandas, Matplotlib, Seaborn, Requests, Re, Pickle, NLTK, Streamlit, Streamlit Extras, Streamlit Lottie  
- **ML & NLP:** Scikit-learn (Logistic Regression, Naive Bayes), TensorFlow, Keras, Text preprocessing, TF-IDF vectorization  
- **Deployment & Tools:** Streamlit Cloud, Git, YouTube API
